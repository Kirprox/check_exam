# CheckExam Service

Сервис checkexam предназначен для хранения результатов пользователей по экзаменам.

Сервис реализован на Spring Boot и является частью микросервисной архитектуры, развернутой в Kubernetes.

### Назначение сервиса

Сервис хранит информацию о том, какой пользователь сдавал какой экзамен.

#### Каждая запись содержит:

id записи

clientId — идентификатор пользователя

descId — идентификатор экзамена

### Основная логика сервиса

Сервис не хранит название экзамена, только его идентификатор.

Для получения названия экзамена сервис обращается к checkdesc.

Таким образом происходит обогащение данных.

### Клонирование проекта

Проект состоит из трёх репозиториев и имеет следующую структуру:
```
project/
├── check_desc/
├── check_exam/
└── check_infra/
```

check_desk - https://github.com/Kirprox/check_desc

check_exam - https://github.com/Kirprox/check_exam

check_infra - https://github.com/Kirprox/check_infra

Необходимо скачать их в одну папку.

### Сборка Docker-образа

Сборка и публикация выполняется через bat-файл из check_infra.

### Запуск в Kubernetes

Перейти в папку check_infra
Выполнить:
kubectl apply -f k8s/

Включить ingress (если не включен):
minikube addons enable ingress

При необходимости выполнить:
minikube tunnel

### Доступ к API

После запуска:

http://127.0.0.1/desc - вернет список экзаменов

http://127.0.0.1/exam - вернет список пользователей и их экзаменов
